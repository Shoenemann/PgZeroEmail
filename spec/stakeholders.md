# Zeroemail

## The stakeholders want that

- Zeroemail is an educational game that teaches users to be productive with their emails
- The main quests of Zeroemail can be completed in not too much time, in the order of an hour
- That the main goal of the game is to unlock and memorize all the Gmail shortcuts
- The main game window is a simplified fictional email inbox and that the fictional emails one receive in the game have some humour
- The game is written in python pgzero and there are simple instructions on how to run it in your computer
- That few recognizable emails in the game are essential for the storyline, while the other emails are just used for the game quests and minigames
- That from the first to last level you witness some character development and story development
