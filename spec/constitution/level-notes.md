# ZeroEmail Level Notes

Quick lookup guide for each level in the campaign.

## Level 1: First Dispatch

### Commands learned:
- `?` — open keyboard shortcut help
- `/` — search email
- `z` — undo last action
- `o` or `Enter` — open conversation
- `u` — back to threadlist

## Level 2: The Mailbox Map

### Commands learned:
- `j` — older conversation
- `k` — newer conversation
- `n` — next message in conversation
- `p` — previous message in conversation
- `gi` — go to inbox
- `gs` — go to starred
- `gb` — go to snoozed
- `gt` — go to sent
- `gd` — go to drafts
- `ga` — go to all mail
- `gc` — go to contacts
- `gk` — go to tasks
- `gf` — go to search filters
- `gl` — go to label
- `gn` — next page
- `gp` — previous page

## Level 3: Correspondence Under Pressure

### Commands learned:
- `c` — compose
- `d` — compose in a new tab
- `r` — reply
- `a` — reply all
- `f` — forward
- `R` — reply in a new window
- `A` — reply all in a new window
- `F` — forward in a new window

## Level 4: Triage at Monteluce

### Commands learned:
- `e` — archive
- `#` — delete
- `!` — report spam
- `m` — mute conversation
- `y` — remove label
- `s` — toggle star
- `Shift + i` — mark as read
- `Shift + u` — mark as unread
- `_` — mark unread from here
- `+` or `=` — mark as important
- `-` — mark as not important
- `b` — snooze

## Level 5: The Evidence Sweep

### Commands learned:
- `x` — select conversation
- `*a` — select all
- `*n` — deselect all
- `*r` — select read
- `*u` — select unread
- `*s` — select starred
- `*t` — select unstarred
- `.` — open more actions menu
- `v` — open move to menu
- `l` — open label as menu
- `,` — move focus to toolbar

## Level 6: Read the Whole Story

### Commands learned:
- `;` — expand all
- `:` — collapse all
- `[` — remove label & go to next conversation
- `]` — remove label & go to previous conversation
- `{` — archive & go to next conversation
- `}` — archive & go to previous conversation

## Level 7: The Bellafonte Finale

### Commands learned:
- All commands from the earlier levels, used together in one full workflow
- Any missed commands are replayed as drills before the final check
