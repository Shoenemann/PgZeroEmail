# ZeroEmail

ZeroEmail is a keyboard-first Pygame Zero inbox game that teaches Gmail shortcuts through story-based practice.

## Requirements

- Python 3.11+
- Pygame Zero

## Local setup

1. Create and activate a virtual environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Launch the game:
   ```bash
   pgzrun main.py
   ```

## Project structure

- `main.py` — Pygame Zero entry point
- `zeroemail/` — game logic and data models
- `tests/` — automated smoke and model tests
